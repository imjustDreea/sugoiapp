📖 Descripción General

sugoiapp es una plataforma web full-stack diseñada como red social multimedia para explorar, descubrir y recomendar contenido de:

  • 🎬 Anime - Series animadas con integración a API Jikan
  • 📖 Manga - Cómics y mangas digitales
  • 🎮 Videojuegos - Base de datos de juegos
  • 🎵 Música - Recomendaciones musicales

La aplicación combina características de plataformas como MyAnimeList, TMDB, y redes sociales, permitiendo a los usuarios:

  • Descubrir contenido multimedia
  • Crear y gestionar bibliotecas personales
  • Compartir recomendaciones con otros usuarios
  • Seguir a otros usuarios e interactuar
  • Personalizar su perfil con temas y badges

🎯 Objetivos del Proyecto

Objetivos Generales

  • Crear una plataforma integrada para gestionar múltiples tipos de contenido multimedia
  • Permitir que usuarios descubran y compartan recomendaciones
  • Implementar un sistema modular y escalable para futuras integraciones

Objetivos Técnicos

  • Desarrollar una API REST robusta con autenticación JWT
  • Crear una interfaz moderna con React/TypeScript/Vite
  • Integrar APIs externas (Jikan, etc.)
  • Implementar persistencia con PostgreSQL
  • Aplicar buenas prácticas de seguridad (bcrypt, JWT)

Objetivos de Usuario

  • Registro e inicio de sesión seguro
  • Gestionar biblioteca personal de contenido
  • Crear y compartir posts con la comunidad
  • Ver perfiles públicos y seguir usuarios
  • Marcar contenido como favorito o para ver después

Puntos Clave

🗄️ Base de Datos

PostgreSQL con pool de conexiones. Tablas principales:

  • users - Usuarios registrados
  • profile - Perfiles extendidos (1:1)
  • library_items - Biblioteca personal
  • anime_likes - Likes en anime
  • posts - Posts de comunidad
  • followers - Sistema de seguidores

🔌 API Endpoints

Estructura modular en api/:

  • auth/ - Login, registro, usuario actual
  • anime/ - CRUD anime + caché
  • manga/ - CRUD manga
  • games/ - CRUD videojuegos
  • music/ - CRUD música
  • library/ - Biblioteca personal
  • posts/ - Posts comunidad
  • profile/ - Gestión de perfiles

⚡ Características Especiales

  • 💾 Caché en memoria para reducir llamadas a APIs externas
  • 🚫 Filtrado de contenido (hentai prohibido)
  • 🔄 Retry automático con backoff exponencial
  • 📊 Migraciones automáticas de tablas
  • 🔐 Validación JWT en todas las rutas protegidas

📊 Base de Datos

Tabla users

id SERIAL PRIMARY KEY
username VARCHAR(50) UNIQUE NOT NULL
email VARCHAR(100) UNIQUE NOT NULL
password TEXT NOT NULL (hasheada con bcrypt)
name VARCHAR(100)
last_name VARCHAR(100)
created_at TIMESTAMPTZ DEFAULT NOW()

Tabla profile (1:1 con users)

user_id INTEGER PRIMARY KEY (FK users)
avatar_url TEXT
banner_url TEXT
bio TEXT
theme JSONB (colores personalizados)
badges JSONB (insignias ganadas)

Tabla library_items

user_id INTEGER (FK users)
media_type TEXT ('anime', 'manga', 'games', 'music')
list_key TEXT ('favorites', 'later', 'completed')
external_id TEXT
title TEXT
image_url TEXT
meta JSONB (metadata flexible)
created_at TIMESTAMPTZ
PRIMARY KEY (user_id, media_type, list_key, external_id)

Tabla posts

id SERIAL PRIMARY KEY
user_id INTEGER (FK users)
content TEXT NOT NULL
media_type TEXT
media_id TEXT
images JSONB (URLs de imágenes)
likes_count INTEGER DEFAULT 0
created_at TIMESTAMPTZ

Tabla followers

follower_id INTEGER (FK users)
following_id INTEGER (FK users)
created_at TIMESTAMPTZ
PRIMARY KEY (follower_id, following_id)

🌐 API REST

Base URL

Development: http://localhost:3000
Production: https://sugoihub.onrender.com

Autenticación

Todos los endpoints protegidos requieren:

Header: Authorization: Bearer <JWT_TOKEN>

Endpoints de Autenticación

Método Ruta Descripción
POST /api/auth/login Inicio de sesión
POST /api/auth/register Registro de usuario
GET /api/auth/me Obtener usuario actual

Endpoints de Contenido

Tipo Método Ruta
Anime GET /api/anime (búsqueda, filtros)
Anime GET /api/anime/:id (detalle)
Manga GET /api/manga (búsqueda)
Games GET /api/games (catálogo)
Music GET /api/music (búsqueda)

Endpoints de Biblioteca

GET    /api/library/anime/favorites
POST   /api/library/anime/favorites
DELETE /api/library/anime/favorites/:id

Tipos: anime, manga, games, music
Listas: favorites, later, completed

Endpoints de Posts

GET    /api/posts (listado)
POST   /api/posts (crear)
GET    /api/posts/:id (detalle)
DELETE /api/posts/:id (eliminar)
POST   /api/posts/:id/like (marcar like)
DELETE /api/posts/:id/like (quitar like)

Endpoints de Perfiles

GET    /api/profile/:username (perfil público)
GET    /api/profile/me (mi perfil)
PUT    /api/profile/me (editar)
POST   /api/profile/avatar (subir avatar)
POST   /api/profile/banner (subir banner)

🔐 Flujo de Autenticación JWT

1. Registro

Usuario llena formulario → Frontend valida → POST /api/auth/register → Backend hashea contraseña → Crea usuario + perfil → Genera JWT → Retorna token

2. Login

Usuario introduce credenciales → POST /api/auth/login → Backend valida contraseña → Genera JWT (7 días) → Frontend almacena en localStorage

3. Peticiones Autenticadas

Frontend incluye header Authorization: Bearer <token> → Backend valida JWT → Extrae usuario → Continúa con lógica

Características del Token JWT

{
  "id": 2,
  "username": "andaa",
  "email": "andaa@example.com",
  "iat": 1642432800,
  "exp": 1643037600
}

Validez: 7 días desde emisión
Almacenamiento: localStorage (key: 'token')
Seguridad: Contraseña hasheada con bcrypt (10 rounds)

💻 Instalación y Configuración

Requisitos

  • Node.js 18+ (node --version)
  • PostgreSQL 13+ (psql --version)
  • npm 8+ (npm --version)

Paso 1: Clonar Repositorio

git clone https://github.com/imjustDreea/sugoiapp.git
cd sugoiapp

Paso 2: Configurar Backend

cd sugoiHub/backend
npm install

# Crear archivo .env con:
DATABASE_URL=postgresql://usuario:contraseña@localhost:5432/sugoiapp
JWT_SECRET=tu_clave_secreta_muy_segura
NODE_ENV=development
PORT=3000

# Iniciar servidor
npm run dev

Paso 3: Configurar Frontend

cd sugoiHub/frontend
npm install

# Iniciar dev server
npm run dev

Paso 4: Ejecutar Ambos (Recomendado)

# Desde raíz del proyecto
npm run dev

# Backend en http://localhost:3000
# Frontend en http://localhost:5173

Build para Producción

# Frontend
cd sugoiHub/frontend
npm run build
npm run preview

# Backend (solo ejecutar)
npm start
